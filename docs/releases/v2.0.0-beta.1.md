# ImagoTune 2.0.0 Beta 1

ImagoTune 2.0 的第一个公开测试版。2.0 带来全新品牌、中英双语界面、可自定义的布局编辑器，以及多供应商管理，让创作、配置和本地后期都更顺手。

## 更新内容

- 全新 ImagoTune 品牌与新版应用图标；启动页新增「想象变成图片」书写动画。
- 布局编辑：创作、图片编辑、智能扩图页支持自定义模块位置、大小与隐藏，并提供布局分享码、撤销重做和拖动推挤。
- 中英双语界面即时切换；安装程序支持简体中文与英文。
- 多供应商管理：可保存多个 OpenAI 兼容平台，并按「生图 / 图反推 / 提示词增强」三角色分配模型；内置 12 个平台预设（混元、智谱、火山方舟、阿里云百炼、硅基流动、xAI、OpenRouter 及五个国际站预设）；新增模型快捷切换面板。
- 设置页改为分区导航（连接与模型 / 通用设置 / 软件更新 / 关于与帮助）；顶部导航精简，设置入口移至侧栏。
- 全局悬浮提示替代原生 title 提示；生成、增强、反推、导出、队列与本地 AI 使用统一进度反馈。
- 侧栏项目树支持展开预览最近图片；顶栏新增队列进度芯片；队列历史可一键清空。
- 图库修复灯箱层级，新增本地打开（默认程序 / 资源管理器定位）与跨页跳转定位。
- 本地 AI 在双显卡设备上强制使用高性能 GPU 推理；模型列表与徽标更稳健。
- 创作页模块支持折叠收缩，布局持久化更稳定。

## 升级说明

从 v1.5.x 升级：

- 设置、API 密钥、图库、模板、队列、保存目录和更新偏好都会自动迁移，无需手动操作。
- 新版安装程序带有新的应用标识，会自动检测、卸载并接管已安装的旧版（v1.x），同时保留用户数据。
- 界面语言跟随系统语言：首次启动时，中文系统保持中文，其他系统默认英文，可随时在「设置」中切换。
- 旧版本遗留的排队任务需要手动重试。这是刻意设计，避免重复计费。

## 验证

TypeScript 检查通过；520 项自动化测试通过；生产构建与 Windows NSIS 安装包完整性验证通过。

## 说明

- 本次为测试版：只有把更新渠道选为「测试版 Beta」的用户才会收到，正式版渠道用户不受影响。
- 已知问题：新加入的若干平台适配器（智谱 / 火山方舟 / 阿里云百炼 / 硅基流动 / xAI / OpenRouter）尚未对线上 API 实测，模型 ID 可能因平台而异。
- 安装包未进行代码签名，Windows SmartScreen 可能显示提醒。

# ImagoTune 2.0.0 Beta 1 (English)

The first public beta of ImagoTune 2.0. Version 2.0 brings a new brand, a bilingual Chinese/English interface, a customizable layout editor, and multi-provider management, making creation, configuration, and local post-processing smoother.

## What's New

- A new ImagoTune brand and a redesigned app icon; the splash screen now plays a brush-calligraphy writing animation.
- Layout editing: the Create, Edit image, and Outpaint pages support custom module position, size, and hiding, along with layout share codes, undo / redo, and drag-to-push reflow.
- A bilingual Chinese/English interface with instant switching; the installer supports Simplified Chinese and English.
- Multi-provider management: save multiple OpenAI-compatible platforms and assign models to three roles (image generation / reverse prompt / prompt enhance); 12 built-in platform presets (Tencent Hunyuan, Zhipu AI, Volcano Ark, Alibaba Cloud Bailian, SiliconFlow, xAI, OpenRouter, plus five international-site presets); a new quick model switcher panel.
- The Settings page now uses section navigation (Connection & models / General / Software updates / About & help); the top navigation is trimmed and the Settings entry moved to the sidebar.
- Global tooltips replace native title tooltips; generation, prompt enhance, reverse prompt, export, queue, and local AI now share unified progress feedback.
- The sidebar project tree can expand to preview recent images; a queue progress chip is added to the top bar; the queue history can be cleared in one click.
- Gallery: fixed the lightbox stacking order, and added local opening (default program / reveal in File Explorer) and cross-page jump targeting.
- Local AI now forces high-performance GPU inference on dual-GPU machines; the model list and badges are more robust.
- Modules on the Create page can be collapsed; layout persistence is more stable.

## Upgrade Notes

Upgrading from v1.5.x:

- Settings, API keys, gallery, templates, queue, save directory, and update preferences all migrate automatically, with no manual steps.
- The new installer carries a new app identity and will automatically detect, uninstall, and take over an installed older version (v1.x) while preserving user data.
- The interface language follows the system language: on first launch, Chinese systems stay in Chinese and other systems default to English; you can switch anytime in Settings.
- Queued tasks left over from the old version must be retried manually. This is intentional to avoid duplicate billing.

## Verification

TypeScript checks pass; 520 automated tests pass; the production build and the Windows NSIS installer integrity verification pass.

## Notes

- This is a beta release: only users who set the update channel to Beta will receive it; stable-channel users are unaffected.
- Known issue: the newly added platform adapters (Zhipu AI / Volcano Ark / Alibaba Cloud Bailian / SiliconFlow / xAI / OpenRouter) have not yet been tested against live APIs, so model IDs may differ per platform.
- The installer is not code-signed, and Windows SmartScreen may show a warning.
