# ImagoTune 2.0.0 Beta 1

ImagoTune 2.0 的第一个公开测试版。2.0 带来全新品牌、中英双语界面、可自定义的布局编辑器，以及多供应商管理，让创作、配置和本地后期都更顺手。

## 更新内容

- 全新 ImagoTune 品牌与新版应用图标；启动页新增「想象变成图片」书写动画。
- 布局编辑：创作、图片编辑、智能扩图页支持自定义模块位置、大小与隐藏，并提供布局分享码、撤销重做和拖动推挤。
- 中英双语界面即时切换；安装程序支持简体中文与英文。
- 多供应商管理：可保存多个 OpenAI 兼容平台，并按「生图 / 图反推 / 提示词增强」三角色分配模型；内置 12 个平台预设（混元、智谱、火山方舟、阿里云百炼、硅基流动、xAI、OpenRouter 及五个国际站预设）；新增模型快捷切换面板。
- 设置页改为分区导航（连接与模型 / 通用设置 / 软件更新 / 关于与帮助）；顶部导航精简，设置入口移至侧栏。
- 全局悬浮提示替代原生 title 提示；生成、增强、反推、导出、队列与本地 AI 使用统一进度反馈。
- 侧栏项目树支持展开预览最近图片；顶栏新增队列进度芯片；队列历史可一键清空。
- 图库修复灯箱层级，新增本地打开（默认程序 / 资源管理器定位）与跨页跳转定位。
- 本地 AI 在双显卡设备上强制使用高性能 GPU 推理；模型列表与徽标更稳健。
- 创作页模块支持折叠收缩，布局持久化更稳定。

## 升级说明

从 v1.5.x 升级：

- 设置、API 密钥、图库、模板、队列、保存目录和更新偏好都会自动迁移，无需手动操作。
- 新版安装程序带有新的应用标识，会自动检测、卸载并接管已安装的旧版（v1.x），同时保留用户数据。
- 界面语言跟随系统语言：首次启动时，中文系统保持中文，其他系统默认英文，可随时在「设置」中切换。
- 旧版本遗留的排队任务需要手动重试。这是刻意设计，避免重复计费。
