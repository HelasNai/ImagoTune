# AI Image Studio v1.5.0

本次更新加入完整的新手教程系统，帮助第一次使用的用户快速理解配置、生成、参考图、图库和本地 AI 后期处理流程。

## 新增功能

- 首次启动提供可跳过的欢迎引导，可开始教程、24 小时后提醒或不再提醒当前教程版本。
- 8 步核心教程会自动切换页面并高亮真实功能位置，不会执行生成、连接测试或模型下载。
- 支持上一步、下一步、暂停、恢复、跳过，以及键盘方向键和 Esc 操作。
- 新增常驻教程中心，包含连接配置、首次生图、参考图编辑、图库复用和本地 AI 工具箱五个主题。
- 侧栏和“帮助”菜单均可随时打开教程中心。
- 教程进度按独立内容版本保存在本机，普通补丁更新不会重复打扰用户。
- 窄窗口下教程卡自动切换到底部布局，目标控件缺失时自动使用居中讲解。

## 隐私与费用

- 教程不会读取或记录 API 密钥、提示词和图片内容。
- 教程不会主动调用图片接口、聊天接口或下载本地模型，不消耗 API 额度。

- TypeScript 检查通过。
- 31 项自动化测试通过。
- 完成真实 Electron 八步流程、暂停恢复、教程中心和 980 px 窄窗口验收。
