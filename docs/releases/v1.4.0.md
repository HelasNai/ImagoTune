# AI Image Studio v1.4.0

本次更新加入完全在本机运行的 AI 后期工具箱。图片推理不会读取 API 密钥，也不会上传到第三方服务；模型首次按需下载，安装后可离线使用。

## 新增功能

- Real-ESRGAN 2x / 4x 高清放大，支持透明通道、分块处理和 WebGPU 到 WASM 自动回退。
- ISNet 智能抠图，可导出透明 PNG，并提供边缘优化、羽化和背景预览。
- GFPGAN 人脸优化 Beta，支持修复强度、单脸或多脸处理。
- 一键优化组合流程：人脸优化、2x 超分、智能抠图顺序执行。
- 生成结果、图库和大图预览可直接进入本地工具箱。
- 本地工具箱支持文件导入、拖放和剪贴板粘贴，并提供处理前后对比。
- 本地模型支持暂停、继续、校验、删除和重新下载。
- 模型保存目录可自由更换、打开或恢复默认；迁移时保留原目录作为备份。
- 本地处理结果自动归档为新图片，并记录来源、模型版本、运行设备和处理参数。

## 运行说明

- 推理优先使用 WebGPU；不可用或显存不足时自动使用 WASM/CPU。
- 模型文件不包含在安装包中，需要在“本地工具箱”页面按需下载。
- 人脸优化目前为 Beta；无脸、脸部过小或严重遮挡的图片可能无法处理。
- Windows 安装包未进行商业代码签名，首次下载时可能出现 SmartScreen 提示。
