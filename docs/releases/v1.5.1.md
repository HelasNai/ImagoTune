# AI Image Studio v1.5.1

本次更新聚焦交互体验和视觉反馈，让创作、切页、提示和本地工具操作更连贯。

## 更新内容

- 页面切换加入轻量淡入和上移过渡，减少突然跳转感。
- 成功、错误和进度提示加入平滑出现动画；错误提示增加轻微强调反馈。
- 大图预览、教程、对比和导出弹层加入统一的渐入与弹出效果。
- 按钮、导航、图库卡片、参考图和模型卡片增加悬停、按压和焦点反馈。
- 进度条增加柔和渐变流动效果，空状态图标增加轻微浮动效果。
- 支持系统“减少动态效果”设置，自动关闭非必要动画，兼顾可访问性。

## 验证

- TypeScript 检查通过。
- 31 项自动化测试通过。
- 生产构建、Windows NSIS 安装包和运行时完整性验证通过。

## 说明

- 本版本不改变图片接口、API Key 保存方式、图库数据结构或本地模型处理逻辑。
- 动画仅在渲染进程本地执行，不产生额外网络请求或 API 消耗。
